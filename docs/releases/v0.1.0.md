# v0.1.0

本页记录 `v0.1.0` tag，不代表当前分支用法。当前安装、配置和升级说明见[项目 README](../../README.md)。

## 功能

首个 Go 宿主控制器版本，Windows Agent 继续使用独立的 Rust 包版本。

- VM、后台、交互端和内存的事件驱动观测与断线恢复。
- RemoteApp / 完整桌面切换及独立原生确认窗。
- `start` 使用用户级 systemd；`serve` 提供前台调试。
- 可读 `status`、版本信息，以及当时提供的 `status --json`。
- 离线桌面入口安装、应用目录和图标同步。
- FreeRDP 子进程环境配置。
- 后台与交互端两个端点的共享 token 鉴权。

## 与当前版本的区别

此版本使用旧双端点协议和独立 dialog 模块。当前分支使用单一后台端点、用户 worker 和内嵌确认窗，不兼容旧 Agent 协议。升级时应配套更新两端，并按当前 README 迁移配置。

## 构建与验证边界

检出该 tag 后使用它自己的 `go.mod`、Makefile 和 Rust manifest 构建。在精确 tag 上运行 `make build` 会嵌入 tag 版本与提交号。

构建、单元测试和交叉编译不替代冷启动、RDP 模式切换或故障注入验收。本页不保存本机部署状态、凭据检查结果或临时实验日志。
