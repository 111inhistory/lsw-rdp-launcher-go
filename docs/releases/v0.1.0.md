# v0.1.0

## 范围

首个 Go 宿主控制器版本；Windows Agent 继续使用独立的 Rust 包版本。

- 事件驱动的 VM、后台、交互端及内存观测与断线恢复。
- RemoteApp／完整桌面安全切换，原生确认窗、默认取消、未知会话禁用注销。
- `start` 使用用户级 systemd 后台启动；`serve` 保留前台调试。
- `status` 默认可读输出，帮助和状态显示 CLI 版本；保留 `status --json`。
- `install-shortcuts` 离线安装“Windows 桌面”入口；`sync-apps` 自动维护。
- `[freerdp.env]` 提供仅作用于 FreeRDP 子进程的可选环境变量。
- Windows 两端点共享 token 鉴权；凭据不进入 CLI argv 或控制 socket。

## 工具链与安全

主模块和 GUI 均要求 Go 1.27.3。`make check`、`make build` 显式选择它，不修改系统全局 Go。

Go 1.27.3 修复 [GO-2026-6809 / CVE-2026-111943](https://pkg.go.dev/vuln/GO-2026-6809)：
`crypto/x509.Certificate.Verify` 拒绝一组不再可信的中间 CA。
[官方发布记录](https://go.dev/doc/devel/release#go1.27.3)标注发布日期为 2026-10-19；另一个修复版本为 Go 1.26.10。

本项目的 RDP TLS 由外部 FreeRDP 处理，此次工具链更新不改变其证书策略，也不更新系统 CA 包。
Go 二进制已使用修复后的工具链重新构建。

## 验证

- `make check`：主模块、GUI，以及 Windows agent clippy／交叉编译检查通过。
- Go 1.27.3 下对两个 Go 模块运行 govulncheck v1.9.0，未报告可达漏洞。
  主模块仍有被导入包／依赖模块的不可达漏洞记录，不声称依赖完全没有已知漏洞。
- 已验证生产 token、Windows token ACL、后台及 RemoteApp 交互鉴权和盘符查询。
- 双向显示模式切换和完整冷启动仍未完成最终实机验收；本版本不声称已经通过这些项目。

## 构建

检出 `v0.1.0` 后运行 `make build`。产物位于 `bin/`，CLI 嵌入 tag 版本与提交号；
非精确 tag 构建显示 `dev`，脏工作区仍有标记。
