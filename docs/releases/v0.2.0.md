# v0.2.0

## Highlights

- Single Go CLI with an embedded native confirmation window; no separate dialog executable.
- Explicit Desktop / RemoteApp switching: execute in the current desktop, retain the login and reconnect, log off the identified login, or cancel.
- User actions bind to a complete Windows logon reference and configured SID. The backend validates the same token handle used to create the user worker.
- Ordered multi-file requests share one confirmation; completed items are not replayed after a partial failure.
- Event-driven VM and memory management, bounded operation deadlines, and explicit recovery for unsafe memory preparation.
- Clearer human-readable status, labelled historical observations while paused, and grouped English help with consistent long-option spelling.
- Fixes a native GTK crash when closing the confirmation window from a draw callback, which previously disconnected IPC before the choice was sent.

## Upgrade

Update the Linux CLI and Windows Agent together. Agent and private host IPC protocols are version 2; old global interactive endpoints are not supported.

- Remove obsolete configuration keys `server.agent_port`, `ui.dialog_bin`, and `lifecycle.reclaim_virtio_mem`.
- Use the Agent's `remoteapp-shell` role for RemoteApp and keep `client_hostname` stable.
- Remove legacy shortcut entries that reference an old CLI path. Run `rdp-launcher install-shortcuts` to rebuild entries from the local cache.
- Generated shortcuts and icons are disposable. Catalog publishing may leave partial updates after a filesystem failure; fix the underlying error and rebuild the shortcuts.
- Automatic idle logoff is disabled by default. Enabling it closes applications in the identified login; save work first.

See the [README](../../README.md), [Windows Agent guide](../../windows-agent/README.md), and [memory recovery procedure](../memory.md#recovery).

Existing clones and forks can retain the old objects. Re-cloning is recommended; do not merge the old history back into the cleaned repository. Rewriting this repository does not remove third-party copies or cached GitHub views.

## Validation scope

Local Go build, vet and race tests, Rust formatting/lint/build checks, and isolated native GUI regressions were run. Release assets are built by CI; Windows unit tests run natively in its Windows job. These checks do not constitute exhaustive RDP, logoff, or driver integration acceptance.
